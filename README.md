# VetControl 🐾

Sistema web de gestión veterinaria desarrollado como Trabajo Integrador Final de la **Tecnicatura Universitaria en Programación – UTN**.

Permite gestionar propietarios, mascotas, turnos, historias clínicas, vacunas, recordatorios y usuarios según distintos roles del sistema.

## Tecnologías

- React + Vite
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT
- Git / GitHub

## Funcionalidades principales

- Registro, login y recuperación de contraseña.
- Verificación de cuenta por email.
- Gestión de mascotas.
- Reserva, modificación y cancelación de turnos.
- Registro de atención médica e historial clínico.
- Aplicación y control de vacunas.
- Recordatorios.
- Gestión de usuarios y permisos por rol.

## Arquitectura

Backend organizado en capas:

- API
- Application
- Domain
- Infrastructure

Frontend organizado por módulos funcionales.
